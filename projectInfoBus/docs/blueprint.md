# **App Name**: InfoBus

## Core Features:

- Multi-Profile Command Center: Tailored navigation experiences for Aluno, Motorista, and Instituição profiles with profile-specific menus.
- Transit AI Navigator: A generative AI tool that summarizes daily routes and provides 'today's best schedule' based on static timetable data.
- Route & Bus Monitoring Hub: View interactive lists of schedules, vehicle details, and locations optimized for mobile interaction.
- Dynamic Mock Notifications: Integrated bulletin board for reading community announcements and simulating the creation of administrative alerts.
- Driver Logistics Dashboard: Driver-specific views for route visualization and creating route updates with feedback mechanisms.
- Simulated Institutional Management: Lists student records and manages administrative tickets with high-fidelity mock success feedback.
- Performance Mock Reports: Monthly overview visualizations that present simulated performance data for students and institutions.

## Style Guidelines:

- Primary Color: Vibrant Cobalt (#1971C2) symbolizing trust and modern transit infrastructure.
- Background Color: Cool Neutral Off-White (#F1F3F5) to maintain clarity and a mobile-first application aesthetic.
- Accent Color: Bright Cyan (#0B7285) used for active state navigations and success indicators.
- Font Pairing: 'Space Grotesk' for tech-oriented headlines and 'Inter' for high-readability body text in schedules and reports.
- Soft, rounded line icons that emphasize ease of use in a fast-paced transit environment.
- Mobile-first, single-column card layouts with a persistent bottom navigation bar for high-reach usability.
- Smooth side-to-side page transitions that mimic native iOS/Android navigation patterns.
